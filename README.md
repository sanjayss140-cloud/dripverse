## ✨ Features & Architecture

### 1. Luxury Monochrome UI/UX
- **Palette:** Pure Black (`#000000`), Pure White (`#FFFFFF`), Soft White (`#F7F7F5`), Charcoal (`#222222`), Light Grey (`#EAEAEA`).
- **Typography:** Architectural, high-contrast sans-serif editorial typography.
- **Hero & Lookbooks:** High-definition fashion photography and restrained Framer Motion animations.

### 2. Multi-Page E-Commerce Experience
- **Home:** Full-bleed editorial hero, category showcase, Just In (New Arrivals), Featured Philosophy ("LESS, BUT BETTER"), Trending Now, and Brand Statement.
- **Shop All:** Dynamic filtering by category, price slider (₹0–₹20,000), size selectors, and sorting (Featured, Newest, Price Low/High, Rating).
- **Categories:** Dedicated pages for Clothing, Footwear, Accessories, and New Arrivals.
- **Product Details:** High-res multi-angle image gallery, color swatches, size selectors, size guide chart modal, quantity selector, stock availability, specifications, trust badges, and related recommendations.
- **Shopping Bag:** Interactive line items, real-time quantity modifiers, coupon code input, free shipping progress tracker, and order subtotal in INR (₹).
- **Checkout:** Multi-step wizard (Shipping Address, Payment Options with Card / UPI / COD, and Order Review) with encrypted security badges.
- **Wishlist:** Instant save and persistent collection.
- **Account & Orders:** Customer order history, shipping status tracking (Processing, Shipped, Delivered), and profile management.
- **Contact:** Live inquiry form dispatching submissions directly to Sanjay's Gmail inbox (`sanjaysanjay02081@gmail.com`), plus one-click WhatsApp and phone reach.

### 3. Owner & Admin Management Console (`/admin`)
- **Direct Price Modifier:** Modify the selling price and strike-through MRP of any garment in real time.
- **Inventory Control:** Modify stock units per product, with live stock status indicators.
- **Badges Management:** One-click toggles for `NEW`, `TRENDING`, and `FEATURED` flags.
- **Product Creator:** Add new luxury pieces with custom image URLs, categories, sizes, and specs.
- **Orders Management:** Fulfill customer orders, view full customer contact info and delivery addresses, and advance order status.
- **Customer Inquiries Inbox:** Review customer questions submitted via the Contact form with 1-click email/WhatsApp response buttons.
- **Security:** Protected by owner PIN (`DRIP2026`) or one-click authentication as Sanjay (`sanjaysanjay02081@gmail.com`).

## 🛠️ Tech Stack
- **Framework:** React 18 + TypeScript + Vite
- **Styling:** Tailwind CSS + Custom Monochrome Design Tokens
- **Routing:** React Router v6
- **Animations:** Framer Motion
- **Icons:** Lucide React
- **Persistence:** LocalStorage State Synchronization with real-time reactive store

## 🚀 Running Locally

```bash
# Clone the repository
git clone https://github.com/sanjayss140-cloud/dripverse.git
cd dripverse/frontend

# Install dependencies
npm install

# Start Vite development server
npm run dev
```

Visit `http://localhost:5173/` in your browser.
